# Auto-Doc Agent

AI-powered automatic documentation generator for VSCode.

Write code. Hover over any function. See documentation — automatically generated by AI.

## Quick Start

1. Install the extension from the [VSCode Marketplace](https://marketplace.visualstudio.com/items?itemName=JohnyJames.auto-doc-agent)
2. Register at [auto-doc-agent.onrender.com](https://auto-doc-agent.onrender.com) and copy your API key
3. Add to VSCode settings:

```json
{
  "autoDocAgent.apiUrl": "https://auto-doc-agent.onrender.com",
  "autoDocAgent.apiKey": "autodoc_your_key_here"
}
```

4. Reload VSCode and start writing code
