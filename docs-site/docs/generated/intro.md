# Auto-Doc Agent
AI-powered automatic documentation generator for VSCode.

## What It Does
Automatically generates documentation as hover tooltips as you write code — zero effort required.

## Setup
1. Install the extension from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=JohnyJames.auto-doc-agent)
2. Go to [auto-doc-agent.onrender.com](https://auto-doc-agent.onrender.com) and register
3. Copy your token and add it to VS Code settings:
```json
{
  "autoDocAgent.apiUrl": "https://auto-doc-agent.onrender.com",
  "autoDocAgent.jwtToken": "your-token-here"
}
```
4. Start writing code and hover over any function!
