*Last updated: 1/1/1970*

### `multiply`

Multiplies two integers.

This function takes two integer arguments and returns their product. It performs a standard multiplication operation.

**Parameters**
- `a` *(int)*: The first integer operand.
- `b` *(int)*: The second integer operand.

**Returns** `int`: The product of a and b.

*Complexity: O(1) time, O(1) space*
